# Another House Mobile Guide

어나더하우스의 모바일 우선 브랜드 홈페이지 겸 투숙객 가이드입니다.

## 주요 기능

- 한국어·영어·일본어·중국어
- 시간대별 스마트 안내
- 체크인·체크아웃·Wi-Fi·기기·세탁·분리배출 가이드
- 공간 갤러리와 라이트박스
- Google Maps·Naver Map 연결
- 민감한 출입번호와 Wi-Fi 비밀번호는 공개 코드에서 제외
- 정적 사이트와 Vercel clean URL 구성

## 로컬 실행

```bash
npm start
```

`/guide-anotherhouse`에서 확인할 수 있습니다.
